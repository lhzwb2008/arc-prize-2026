# data/examples

这里的 JSON 分两类：

- `demo_fill_color.json`：官方指南里的最小例题（把唯一非零颜色铺满），用来讲输入输出。
- 其余文件：从 [ARC-AGI-2](https://github.com/arcprize/ARC-AGI-2) 公开训练集原样拷贝，许可证为 Apache 2.0。只放了十几道方便离线 demo，不是完整 1000 题。

完整数据请自己拉取：

```bash
git clone --depth 1 https://github.com/arcprize/ARC-AGI-2.git data/full
```
